# UBC Knights Stats

A stats dashboard for the UBC Knights hockey team. Black and gold theme with dark/light mode, sortable leaderboards, goalie stats, team analytics, and season history.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## CSV Formats

**Skaters** (`skaters.csv`):
```csv
Player,GP,G,A,P,PM
John Smith,16,24,9,33,12
```
Column names are flexible — handles `Goals`/`G`, `Assists`/`A`, `Points`/`P`/`PTS`, `PIM`/`PM`, etc. Points auto-calculate from `G + A` if omitted. PPG is calculated automatically.

**Goalies** (`goalies.csv`):
```csv
Player,GP,GAA,SV%,SV,GA,SA,MIN,OTL
Jane Doe,20,6.84,0.844,494,91,585,798,2
```

**Games** (`games.csv`):
```csv
Date,Opponent,GF,GA,Result,OT,Home
2025-10-15,Whalers,4,2,W,0,1
```

**Playoff CSVs** use the same format as regular season, prefixed with `playoffs-`:
- `playoffs-skaters.csv`, `playoffs-goalies.csv`, `playoffs-games.csv`
- Only add these for seasons that had playoffs

**Awards** (`awards.json`):
```json
[
  { "name": "Empty Net Assassin", "description": "Most empty net goals", "winner": "John Smith", "stat": "2 EN goals" },
  { "name": "Glue Guy(s)", "description": "Getting the most spares", "winners": ["Jane Doe", "Bob Jones"] }
]
```
Use `"winner"` for a single winner or `"winners"` (array) for multiple. Only include manual awards — auto awards (Ironman, Cheechoo Train, etc.) are computed from the data.

**Recaps** (`recaps.json` / `playoffs-recaps.json`):
```json
[
  {
    "date": "2024-09-16",
    "opponent": "Smoking Aces",
    "gf": 7, "ga": 3,
    "result": "W", "ot": false,
    "periods": [
      { "name": "1st", "shotsHome": 12, "shotsAway": 8, "goalsHome": 2, "goalsAway": 0 }
    ],
    "goals": [
      { "period": "1st", "time": "00:03:12", "team": "Knights", "scorer": "John Smith", "assists": ["Jane Doe"] }
    ],
    "penalties": [
      { "period": "1st", "time": "00:06:11", "team": "Knights", "player": "Bob Jones", "type": "Interference", "severity": "Minor", "minutes": 2 }
    ]
  }
]
```
For the current season, recaps are generated by `scripts/ingestion.py` (SportNinja API). For older seasons (2023-24, 2024-25), recaps were scraped from Pointstreak using `scripts/pointstreak_scraper.py`.

**All Time** stats are auto-aggregated from all season files — no separate file needed.

## Features

### Tabs
- **Skaters** — sortable leaderboard with GP, G, A, PTS, PPG, PIM. Click any player row to expand a season-by-season breakdown card. Leader cards for top scorer, goal leader, assist leader.
- **Goalies** — sortable table with GAA, SV%, SV, GA, SA, MIN, OTL. SV% semicircle gauges for each goalie.
- **Team** — team record (W-L-OTL), goals for/against, goal differential, roster size, PIM, team SV%. Current form indicator (last 5 games). Opponent breakdown table (sortable). Recent results with expandable game timelines (period-by-period scoring, goals with assists, penalties). Goal distribution donut chart. Comeback wins section.
- **Awards** — end-of-season awards displayed as a card grid (regular season only). Auto awards are computed from stats data (Ironman, Cheechoo Train, Adam Banks, Jumbo Joe, Frequent Flyer, Ghost Checker, Heartbeat Hero). Manual awards are loaded from `awards.json`.

### Season Navigation
- Current season tab
- All Time (aggregated across all seasons)
- History dropdown for past seasons
- Regular Season / Playoffs toggle (appears when playoff data exists for the viewed season)

### Visualizations
- Leader cards (top scorer, goal leader, assist leader)
- Points breakdown bar chart (goals vs assists per player)
- Goal distribution donut chart (team tab)
- SV% semicircle gauges (goalies)
- Season timeline (colored dots by month: green=W, red=L, gold=OTL)
- Cumulative points chart (top 5 scorers progression)
- Milestone tracker (players within 5 of a career milestone)
- Current form indicator (W/L/OTL boxes)

### Other
- Upcoming games show published dates, opponents, home/away, arena, and Vancouver time. Partial schedules are supported; future games never count toward results or player stats.
- A visible refresh timestamp indicates when the schedule was last imported.
- Dark/light mode toggle
- Spotify playlist link in header
- Expandable player cards with per-season sparklines
- Sortable tables throughout

## Pull Stats from SportNinja

```bash
poetry install
poetry run python -m scripts.ingestion --dry-run
poetry run python -m scripts.ingestion
```

Alternatively, with `uv` installed:

```bash
uv run --no-project --with requests --with python-dotenv --with pyyaml python -m scripts.ingestion
```

The importer fetches every stats and game page and all finalized-game timelines.
It validates a complete snapshot before writing, stages the season directory,
and swaps it with rollback on publishing errors. Manual awards and other
competitions remain intact. Network requests have connection/read timeouts.
A local process lock prevents two CLI refreshes from writing simultaneously
(macOS/Linux).

**Credentials:**

1. Copy `config/.env.example` to `config/.env` if it does not already exist.
2. On a desktop browser, log in to SportNinja and open the team page.
3. Open Developer Tools → Network → Fetch/XHR, then reload.
4. Select a `stats` or `games` request. Under Request Headers, copy the value
   after `Bearer ` in `Authorization`.
5. Save it as `SPORTNINJA_TOKEN=...` in `config/.env`. This file is gitignored.
   An expired token causes the import to fail without overwriting saved data.

API configuration in `config/ingestion.yml`:

```yaml
team_id: "vzPOLIu6nhIQ8GXh"
season: "2026-27"
api_base: "https://metal-api.sportninja.net/v1"
timezone: "America/Vancouver"
schedules:
  regular: "QFp35Jr1ctPw0GZX"
  playoffs: null
  tournament: null
```

Set each competition's actual SportNinja schedule ID before importing it:

```bash
poetry run python -m scripts.ingestion --mode playoffs
poetry run python -m scripts.ingestion --mode tournament
```

These write `playoffs-*` and `tournaments-*` files respectively. They never
reuse the regular-season schedule ID as a fallback for another competition.
All-time regular, playoff, and tournament stats remain separate.

**Refresh workflow:** refresh token if needed → import → review the data diff →
`npm test` → `npm run build` → commit and push for deployment. Refresh is manual;
no scheduled automation is configured.

The importer refuses to remove existing players or completed games by default.
For a verified official correction (such as a changed date/name), preview with
`--dry-run --allow-removals`, review the source, then import with
`--allow-removals`. This flag does not bypass malformed responses or missing
recaps. Dates use Vancouver local time, so older UTC-date imports may need a
reviewed correction if re-imported.

### September 19, 2026 correction

The owner confirmed game `421ajaRC5CqOWcpC` (Knights 8–2 Havana Outlaws) is final,
although SportNinja still marked it scheduled and returned empty player totals.
`confirmed_final_games` in the ingestion config explicitly enables this one-game
fallback. Stats are reconstructed from goals, assists, penalties, shots, and the
active game roster. Inactive players receive no games played. Shawn Rassekh's
39 minutes use the three recorded 13-minute periods, assuming he played the
entire confirmed final game (no goalie changes). The correction is documented
in `corrections.json` and identified in the app.

On the next refresh:

- If SportNinja marks the game final, the importer automatically uses official
  totals, clears the active correction metadata, and does not add summary stats.
- If SportNinja still has the wrong status but begins returning player totals or
  another completed game, the importer stops for reconciliation to avoid double
  counting. Fix the source status or review the correction before proceeding.
- Remove `confirmed_final_games` once a successful official refresh is verified.

This fallback intentionally supports only a single regulation game, one goalie,
no goalie changes, and empty official player totals. It is not a general second
source of season statistics.

## Pointstreak Scraper (Older Seasons)

A one-time script that scrapes game box scores from Pointstreak for the 2023-24 and 2024-25 seasons:

```bash
python scripts/pointstreak_scraper.py
```

Game IDs are hardcoded in the script (sourced from Pointstreak team schedule pages). The scraper parses each box score page and outputs `recaps.json` and `playoffs-recaps.json` files matching the same format used by the SportNinja ingestion. No API key required — data is scraped from public pages.

## Adding a New Season

1. Add the season **first** in `config/seasons.json`; the first entry is current.
   Keep every previous entry for History and career totals.
2. Set `totalGames` to the announced regular-season length, or `null` while
   unknown. Pace projections stay hidden until the length is known.
3. Update `season`, `team_id`, and `schedules.regular` in `config/ingestion.yml`.
   Clear previous competition IDs and temporary game corrections.
4. Run ingestion. It creates `public/seasons/{season-id}/` automatically. If
   launching before the first import, use header-only skater, goalie, and game
   CSVs; `recaps.json` should be `[]` and `upcoming.json` should be
   `{"games": [], "updatedAt": null}`. Never copy old season statistics.
5. Optional playoff, tournament, and manual awards files can be added later.
   Competition controls appear when data exists.

No full schedule is required. The upcoming view displays only published future
games; its date/time labels always use America/Vancouver, including daylight
saving time. Passed start times disappear from the upcoming list while a page
is open; importing is still required to update results or newly published dates.

## Verification

```bash
npm test
npm run build
poetry run python -m unittest discover -s tests -v
```

Tests cover empty awards, active-roster scoring, pagination, request timeouts,
failed-fetch preservation, publish rollback, competition isolation, manual
correction reconciliation, upcoming/result separation, and Vancouver times.
Browser-check current skaters, goalies, team results, the next game, History,
All Time, and phone-width layout before publishing changes.

## Customize

In `src/App.jsx`, edit the config at the top:
```js
const CONFIG = {
  teamName: "UBC Knights",
  established: "2023",
};
```

The knight helmet logo is an SVG component (`KnightLogo`). To use your own logo, replace it with `<img src="/logo.png" />` and drop the image in `public/`.

## Deploy to Vercel

1. Push to a GitHub repo
2. Go to [vercel.com](https://vercel.com) > sign in with GitHub
3. Import your repo — framework auto-detects as Vite
4. Deploy

To update: run ingestion, commit & push. Vercel auto-redeploys.

## Tech Stack

- **Frontend:** React 18 + Vite, PapaParse for CSV parsing
- **Ingestion:** Python 3.11+, requests, PyYAML
- **Styling:** Inline CSS with dark/light theme support
- **Fonts:** Outfit, DM Mono (Google Fonts)
